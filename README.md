# MB Freight – Desktop-Programme

Installer der Desktop-Programme von MB Freight. Dieses Verzeichnis enthält
nur die fertigen Installer, keinen Quellcode.

Die aktuelle Version steht unter **Releases**:

| Programm | Windows | Mac (Apple-Chip) |
|---|---|---|
| MB Freight (Spedition) | `MB-Freight-<Version>-win-x64.exe` | `MB-Freight-<Version>-mac-arm64.dmg` |
| MB Freight Kundenportal | `MB-Freight-Kundenportal-<Version>-win-x64.exe` | `MB-Freight-Kundenportal-<Version>-mac-arm64.dmg` |

Die Programme sind nicht bei Apple oder Microsoft als Hersteller registriert.
Beim ersten Öffnen erscheint deshalb eine Warnung:

- **Windows:** „Weitere Informationen“, dann „Trotzdem ausführen“.
- **Mac:** Systemeinstellungen › Datenschutz & Sicherheit › „Dennoch öffnen“.

Die Programme öffnen dieselbe Oberfläche wie der Browser. Zugangsdaten
erhalten Sie von Ihrer Spedition.
